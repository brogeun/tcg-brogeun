강릉: 기존 공식 포스터 원본을 보존하고, 상단 로고만 16:10 프레임으로 표시한다. 하단 검은 안내문이 나오지 않도록 상단 기준 1.035배를 적용했다. 다른 매장 이미지는 변경하지 않았다.

검증: `test_official_shops.mjs`로 매장번호·도로명 주소·카드 생성·웹/앱 링크 target 검사. `test_official_shops_browser.cjs`로 실제 Chrome의 960px/390px 화면에서 이미지 로딩·16:10 비율·가로 넘침·11개 고유 매장 링크 검사. 화면 캡처는 `debug/official-shops-fix/`에 저장하고 육안 확인했다.

한계: 네이버 플레이스 상세 페이지는 9월 18일 요청 제한(429)으로 직접 열람을 중단했다. 위 매장번호·주소 대조는 정상 응답한 공개 지도 검색 결과에 기반한다. 실제 휴대폰에서 지도앱 전환은 미검증이다. 9월 21일 연결된 휴대폰·에뮬레이터가 없는 것을 확인했으며, 사용자가 직접 실기기 확인하겠다고 명시하고 배포를 요청했다. 해당 승인에 따라 이 수정본을 배포한다.
