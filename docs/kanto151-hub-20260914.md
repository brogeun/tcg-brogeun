## 저장 이전

이전 localhost/chatgpt.site 주소와 tcghub.kr의 브라우저 저장 공간은 서로 다르다. 이전 게임에서 설정 → 저장 내보내기로 JSON 파일을 받고, HUB 게임에서 설정 → 저장 불러오기 → 확인으로 가져온다. 실제 사용자 저장을 자동으로 읽거나 변경하지 않는다. 가져오기는 HUB 게임의 현재 기록을 바꾸므로 확인 화면에서 내용을 확인한다. 가져온 진행을 초기 복귀 기록으로 삼고, 이후 저장대에서 사망 복귀 기록을 갱신한다. 기기 간 자동 저장 동기화는 추가하지 않았다.
