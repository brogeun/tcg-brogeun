# 컬렉션 기능 구현 및 검증

검토일: 2026-10-30 (한국 시간). 이 문서는 구현과 검증 범위를 기록한다. 운영 반영 여부는 해당 커밋의 GitHub Actions 및 배포 결과로 확인한다.

## 적용 범위

| 요구 | 반영 내용 |
|---|---|
| 메뉴 위치 | 기존 카드 정보의 게임 탭에서 치이카와 바로 다음에 컬렉션을 배치. 별도 사이드바 메뉴 없음. 새 게임 탭의 순서 변경에도 위치 유지. |
| 내부 분류 | 작가별 모음 / 캐릭터별 모음 / 나만의 컬렉션. 수집 버튼은 이 영역 안에서만 제공. |
| 작가 첫 화면 | 포켓몬 4명, 원피스 4명의 실제 대표 카드만 노출. 다른 작가는 전체 크레딧 검색으로 접근. 통계적 인기 순위로 표시하지 않음. |
| 추천 작가 | Shinji Kanda, Mitsuhiro Arita, AKIRA EGAWA, Tomokazu Komiya, Eiichiro Oda, Gege Akutami, Boichi, Peach Momoko. 주술회전·Dr.STONE 등 설명과 검증된 대표 그림 포함. |
| 캐릭터 | 포켓몬 1,025종 검색, 독침붕·핫삼 추천, 메가와 진화계열을 각각 명시적으로 선택. 원피스 Character/Leader만 캐릭터 목표로 분류. |
| 개인 목록 | 빈 목록 생성, 이름 변경, 삭제, 카드 개별 추가/제거, 전체/보유/미보유, 진행률. 작가·캐릭터 정보가 없는 Item도 카드 찾아 추가로 선택 가능. |
| 직접 카드 선택 | 게임·언어·이름·번호·세트 코드 검색, 18장씩 표시, 중복 추가 차단. 이미 읽은 다른 언어 카드는 현재 검색에 섞이지 않음. |
| 저장 범위 | 저장 당시 명시적인 카드 ID 목록을 보존. 새 카드가 추가돼도 기존 목표 수는 자동 증가하지 않음. 박스별 컬렉션 생성 기능 없음. |
| 보유와 장부 | 수동 보유 OR 정확히 검증된 개별 카드 자산 보유. 박스·미확인 출처는 자동 전파 제외. holdings/transactions는 읽기 외 수정 없음. |
| 계정과 재시도 | 계정 전환 시 캐시·모달·요청 격리. revision 충돌 처리, 응답 유실 시 동일 mutation ID와 본문 재사용. 기존 숫자형 계정도 호환. |
| 레어도 | 기존 카드 정보 → 박스 수록 카드 패널의 개수 옆에 복수 OR 필터 제공. 검색·개수·페이지 계산 전에 적용하고 상세 복귀 시 복원. |
| 원문 등급 | AR/SAR/RR/MUR 등은 출처에 실제 있는 값만 표시. 무등급·미확인 분리. 번호·이름·평가등급으로 추측하지 않음. JP 보강은 URL·풀번호·원문 이름 일치, OP는 fullId 판본 일치가 필수. |
| 기존 기능 | 최신 시세·추가 게임·DON 검색·기존 인증 경로를 유지하며 통합. |

## 데이터와 출처의 범위

- 기존 카탈로그 62,361행: 포켓몬 JA 18,344 / EN 26,030 / zh-CN 15,002, 원피스 JA 2,985. 원본 831파일이 최신 main과 같은지 대조했다.
- 현재 registry 96,676행은 원본과 출처별 기록을 포함한다. 서로 다른 실물 카드 수가 아니다. 작가 675개 역시 스튜디오·공동 크레딧·표기 차이를 포함한 출처 라벨 수이다.
- 신지 칸다 공식 참조 43개 모두 목표 목록에 연결했다. 29개는 엄격한 메타데이터 조건을 만족한 기존 판본, 14개는 별도 공식 출처 기록이다. 같은 번호의 서로 다른 공식 ID는 임의로 합치지 않았다. 상세는 official-shinji-audit.json 참조.
- 오다 ST01-012_p3/p4와 보이치 P-028_p1은 공식 그림의 Character 표시·정확한 판본·작가 근거를 확인해 캐릭터 발견에만 명시적으로 허용했다. sourceOnly 상태는 유지하며 자산 자동 연결은 하지 않는다.
- 최초 화면에 쓰는 대표 그림은 검증한 파일로 제공한다. 원문 주소가 깨진 독침붕·이브이는 같은 캐릭터의 기존 판본으로 교체했고, 원문·파일 해시를 보존했다.
- 붙여 쓴 판매처 표기(예: Beedrill V RR[set number](pack))를 처리하되 Spirit Link 같은 아이템을 종으로 오인하지 않게 검사했다.
- 작가와 종 사전은 체크인된 출처 스냅샷이다. 미확인 작가 크레딧·언어·지역·판본은 추측해서 확정하지 않는다. zh-cn 제공자 자료는 전부 간체 중국 실물판으로 검증된 것이 아니다. 카탈로그에 없는 마켓 전용 상품도 이름만으로 강제 병합하지 않는다.

현재 버전: 20261029-cp1-024b30901ef0. 카드 ID는 게임·언어·원본 sourceKey의 UUIDv5로 고정한다. 재생성 시 기존 기록을 보존하며, manifest는 16개 키 파일과 버전·내용 검증 후 마지막에 원자적으로 쓴다.

실제 사용자 계정 생성/수정, 운영 D1 쓰기, 실물 iOS/Android 기기 테스트를 했다는 뜻은 아니다. 운영 DB 설정과 비밀값은 변경하지 않으며, 기존 런타임 지문 검사를 배포 전후 유지한다. 개인 API는 no-store이고 서비스워커에 저장하지 않는다.

## 재현

전체 저장소 체크아웃에서 다음을 실행한다.

```sh
python scripts/build_collection_catalog.py --repo . --sources-dir data/collections/sources --output data/collections --offline
node scripts/test_collections_release.mjs
```

외부 연구 폴더·워크스테이션 경로·네트워크 호출 없이 소스 캐시와 저장소의 원본 데이터/검증 이미지를 사용한다. 개인 목표는 공개 카탈로그 재생성과 별도로 보존한다.
