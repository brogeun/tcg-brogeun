# 화면 가림 축소 · 배구 스와이프 — 2026-09-26

## 4. KANTO151 UI — 완료

- 기본 HUD에서 긴 목표 설명·키보드 안내·중복 도감 버튼을 접었습니다. 방향/거리 목표는 작은 버튼으로 남겨, 누르면 전체 지도와 자세한 목표를 봅니다.
- 미니맵은 작은 `주변 지도 +`로 시작하고 눌러 펼칩니다. `정보 +`로 상세 정보와 지도도 펼칩니다. 전투 중에는 상대 체력과 겹치지 않게 지도 미리보기를 접고, 지도 버튼은 전체 지도를 엽니다.
- 모바일에서는 기술을 평소에 접고 전투 중 자동 표시합니다. `기술 +/−`로 직접 열고 닫을 수도 있습니다. 공격·대상·회피·포획·가방·도감은 계속 접근할 수 있습니다. 멀리 끌어 달리기는 유지하고 중복 달리기 버튼만 접었습니다.
- 상호작용 설명과 행동 버튼을 모바일에서 하나의 카드로 합쳤습니다. 대상이 없으면 빈 버튼을 숨기며, 사용 불가 이유는 계속 보여줍니다. 자세한 부가 설명은 `정보 +`에서 봅니다.
- 알림은 최대 두 개로 줄였고 일반 알림은 짧게 표시합니다. 중요한 경고의 상세 문구는 유지합니다. 지역 진입 연출도 전체 화면을 덮는 형태에서 작은 안내 카드로 바꿨습니다.
- 체력·허기·갈증·휴대 보급량·포획 수량은 숨기지 않습니다. 가로 화면에 남아 있던 이전 위치 규칙을 정리했습니다.

같은 시작 캠프, 같은 파트너, 같은 화면 크기의 **눈에 보이는 HUD 사각 영역 합집합**을 측정했습니다. 글자와 투명 배경을 포함한 면적 추정이며 불투명 픽셀의 정밀 측정은 아닙니다. 팝업·야생 이름표는 산정에서 제외했습니다.

## 5. 피카츄배구 스와이프 — 완료

- 코트에서 **좌우로 끌기 = 이동**, **위로 쓸기 = 점프 공격**, **아래로 쓸기 = 슬라이딩**입니다. 이동 손가락을 유지하면서 두 번째 손가락으로 공격할 수 있습니다.
- 짧은 터치나 미세 흔들림은 공격하지 않습니다. 한 번의 위/아래 제스처는 한 번만 실행하며, 보통 손 떼기는 이미 누른 점프 공격을 마치되 이동은 멈춥니다. 취소·일시정지·화면 회전·창 비활성화 시 입력을 정리합니다.
- 큰 방향·행동 버튼은 기본적으로 접었습니다. `버튼 조작`을 누르면 기존 방식도 사용할 수 있습니다. 키보드는 그대로입니다.
- 기존 점프 공격 버튼과 같은 입력 버퍼를 사용합니다. 공을 자동 추적하거나 방향을 보정하지 않습니다. 물리·난이도·승패·점수·서버 리플레이 판정은 변경하지 않았습니다.
- 확대 화면에서 버튼 전용으로 비워 두던 좌우 공간을 해제했습니다. 코트의 원래 화면 비율과 세로 전환 시 일시정지는 유지합니다.
