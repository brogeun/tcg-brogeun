# Card Info 가격 전수 검사 — 2026-10-30

수정 소스: `338365c5e8cbcd5d7201cda8efbe1ef1508d4b3e`

## 검사 범위

- 일본판 원본: 431개 세트 파일, 27,189개 카드 행.
- 현재 화면에 노출하는 일본판: 215개 세트, 21,330개 카드 행.
- 추가 6개 게임: 112,236개 카드 행, 기존 SNKRDUNK 가격 4,405건 전부 유지.
- OP16 정규 그림 149종, OP17 정규 그림 158종은 각기 다른 정확한 상품으로 연결되는 것을 검사했다.
- EB05 100종은 기존 전용 스냅샷 연결이다. 이번 신규 복구 수에 포함하지 않았다.

## 확인한 원인과 수정

1. 같은 카드 번호의 기본판·패러렐·만화판이 서로 다른 시장 상품인데 연결 증거가 부족했다.
   - 별도 이미지 연결 612건(포켓몬 135건, 원피스 477건)을 추가했다.
   - OP17은 검토한 158개 판본별 명시적 연결을 반영했다.
   - 이미지 유사도 확장 기준은 독립적으로 검토한 OP17 158종으로 검증했다. 기준을 통과한 대조군 145종 중 잘못 수락된 연결은 0건이다.
   - 초판·서명·시리얼·세트 상품 등 판본 위험 항목은 자동 연결에서 제외했다.
2. 상품 원본 가격 로딩이 검색 이름/별칭 로딩에 묶여 있었다.
   - 카드 정보 및 두 상세 보기는 가격 상품 로더를 직접 공유한다.
3. 일본 상품 페이지 실패 시 PSA10만 재조회하던 서버 경로가 있었다.
   - 일반 A급·PSA10·PSA9을 별도로 조회하고, 실패는 명시적 매물 없음과 분리한다.
4. 해외 카탈로그가 비었다는 이유만으로 다른 상점 가격으로 넘어갈 수 있었다.
   - 연결된 정확한 상품의 일본 실시간 매물 상태를 먼저 확인한다.
5. 원화 표시와 환율 준비 순서가 일관되지 않았다.
   - 원본 금액/통화를 보존하고, 표시 때 공통 환율로 원화 환산한다.
   - 실시간 가격은 원래 통화와 이미지를 함께 캐시해서 상세 창에서 다시 소실되지 않게 한다.
   - 이전 가격 응답을 재사용하지 않도록 캐시 버전을 갱신했다.
6. 박스 구성 카드 목록의 요청하지 않은 가격 표시는 앞선 수정에서 제거했고, 이번 검사에서도 그 상태를 유지했다.
