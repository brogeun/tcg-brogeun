# TCGHUB 구형 카드 이미지 이어받기

1. 받은 ZIP을 **완전히 압축 해제**합니다. ZIP 내부에서 CMD를 실행하지 마세요.
2. 압축을 푼 폴더의 `TCGHUB_Vintage_Backfill.cmd`를 더블클릭합니다. Python 3.11 이상이 필요합니다. 최초 실행은 이미지 검증 모듈을 설치합니다.
3. 완료 또는 일부 중단 메시지가 나오면 같은 폴더의 `TCGHUB_Vintage_Backfill_Result.zip`을 대화에 첨부합니다. **일부 항목이 남아도 결과 ZIP을 보내면 됩니다.**

대상은 검증된 구형 카드 이미지 **3,393개, 41개 세트**입니다. 출처는 TCG Collector 3,385개와 Pooka 8개이며, 전체 이미지 크기는 약 **247 MiB**입니다. 최초 다운로드 시간은 인터넷과 출처 서버 응답에 따라 달라집니다.

중간에 창을 닫거나 인터넷이 끊겨도 `.backfill-cache`에 저장된 정상 파일은 유지됩니다. **같은 폴더에서 같은 CMD를 다시 실행**하면 검증 완료한 파일은 재사용합니다. 폴더와 `.backfill-cache`를 지우거나 새 폴더로 다시 압축 해제하면 기존 진행 상황을 사용할 수 없습니다.

403/429는 출처 서버의 요청 거부입니다. CMD 자체가 거부를 해결하거나 우회하지는 않습니다. 해당 출처의 요청을 중단하고 다른 독립 출처의 진행 상황과 이미 받은 파일을 보존합니다. 반복 실행으로 거부된 출처에 계속 요청하지 말고 결과 ZIP을 먼저 보내주세요.

현재 창의 출력은 `TCGHUB_Vintage_Backfill.log`에도 계속 기록됩니다. 창은 실행이 끝나면 아무 키나 누를 때까지 열려 있습니다. 동일 폴더에서 두 번 더블클릭하면 두 번째 실행은 기존 작업을 덮어쓰지 않습니다.

결과 ZIP에는 해시 검증을 다시 통과한 이미지, 원본 검토 목록, 완료·잔여·거부 출처를 기록한 상태 보고서만 들어갑니다. 로그인·Git 설치가 필요 없고, 이 프로그램은 저장소나 사이트에 자동 반영하지 않습니다. 결과를 현재 저장소와 대조해 안전하게 가져온 뒤 배포합니다.
