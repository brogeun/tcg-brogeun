# 피카츄배구 점프·슬라이딩 두 버튼과 옵션 — 2026-09-27

## 구현 완료

- 행동 버튼을 **점프 / 슬라이딩** 두 개로 정리하고 기본 화면에 표시합니다. 이동은 코트 좌우 드래그입니다. 상하 스와이프 공격은 꺼서 이동 중 오입력을 줄였습니다.
- 점프 한 번은 즉시 점프합니다. **0.35초 이내에 두 번째로 누르면 같은 점프에 스파이크를 한 번 연결**합니다. 첫 점프를 두 번 탭 판정까지 기다리지 않습니다. 길게 누르거나 손가락이 버튼 경계를 왕복하는 동작은 자동 연타가 되지 않습니다.
- 일시정지, 입력 취소, 선수/랠리 교체 때 입력을 정리하며 기존 스파이크 대기시간과 리플레이 입력 형식을 유지합니다. 물리·AI·캐릭터 능력·점수·랭킹 규칙은 그대로입니다.
- 음량, BGM 켜기/끄기, 보조 방향 버튼, 다시 시작을 **옵션 팝업**으로 옮겼습니다. 경기 화면에는 옵션·일시정지·확대만 남겼습니다.
- 옵션을 열면 경기와 입력을 멈춥니다. 닫기만으로 재개하지 않으며 기존 계속하기/카운트다운을 사용합니다. 확대 화면에서도 옵션을 열 수 있고 Escape로 닫아도 확대 상태를 유지합니다. 음량과 BGM 선택은 새로고침 후에도 유지합니다.
