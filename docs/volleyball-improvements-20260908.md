# Volleyball improvements — 2026-09-08

Mobile movement supports dragging a captured finger between direction buttons and preserving a second action finger. A 120 ms input buffer retains quick jump, slide and spike taps until the existing player mechanics accept them. The recorded replay contains the exact sampled controls; the server does not need to emulate the client input buffer. Holding jump/slide still triggers once per press. Skill buttons display cooldown and spike readiness. Narrow landscape layouts reserve space beside the court for 48 px controls.

Resuming a paused match shows a cancelable three-second countdown without advancing simulation or ranked duration. Both rotation directions, actual viewport resizing and hidden pages pause play. Fullscreen transitions guard against late requests and failed exits. Completed matches show successful player spikes/saves, the longest rally across both players and elapsed simulation time. Registration status and retry/discard controls are also available inside the fullscreen result panel. Mobile character descriptions remain hidden; the supplied BGM and saved volume remain in use.

Rules v4 allow the opponent to block during the previous hitter's contact cooldown. Hard AI checks whether a low ball can be reached by running before diving. Existing leaderboard records/schema are preserved. Active v3 sessions replay with original v3 physics; new sessions use v4, and the submitted replay version must match the stored session version.

Validation: gameplay, member leaderboard, sixteen input tests, feedback/countdown, fullscreen lifecycle and sprite-pose tests pass. Captured pre-change v3 fixtures pass for all three difficulties; current and legacy authenticated local API submissions, version mismatch rejection and idempotency are covered. The changed Pages function compiles with Wrangler. Browser checks cover start, keyboard slide, pause/resume countdown, resize pause, completed normal/hard practice matches, mobile results, 390 px portrait and 844/667 px landscape.
