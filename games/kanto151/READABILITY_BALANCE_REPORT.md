# 지도·안내·생존·볼 수량 개선 (2026-09-15)

이번 범위는 지도 가독성, 장식 표지판 제거, 필드 능력 힌트, 생존 소모·몬스터볼 지급 조정입니다. 기존 5지역·151종·개체 ID·진화·출현 조건·이로치·보스·퍼즐 데이터를 유지했습니다. 실제 사용자 저장에 접근하지 않았습니다.

## 변경 내용

1. **지도 — 완료**: 좁은 두 열 배치와 지도 위 겹치는 장소 이름을 없앴습니다. 지도는 창 너비를 사용하며, 밀집 장소는 숫자로 묶고 누르면 이름·거리·할 일을 목록으로 고릅니다. 확대/축소, 장소까지 걸어가기, 지역 이동을 유지했습니다. 모바일 목록·확대 버튼은 44px 이상입니다. 메뉴 전체 크기를 다시 키우지는 않았습니다.
2. **표지판 — 완료**: 5지역 장식 표지판과 시작 캠프의 중복 지도 안내판을 제거했습니다. 저장대·식수대·쉼터 표식은 기능이 있어 유지했습니다. 검수 중 저장대와 같은 좌표의 보급 상자가 선택되지 않는 문제도 발견해 안전한 주변 위치로 분리했습니다. 기존 상자 ID와 수령 기록은 유지합니다.
3. **필드 능력 힌트 — 완료**: 풀베기 등 6개 능력은 기존의 특정 포켓몬 계열 포획 또는 도감 등록 조건으로 자동 해금됩니다. 기술머신 소비나 전투 기술 장착을 요구하는 시스템이 아닙니다. 대상 앞에서 실제 해금 조건과 사용법 위치를 안내하고, 지도에 효과·조건·E/모바일 행동 버튼 사용법을 제공합니다. 잠김 안내가 모바일에서 잘리던 문제도 수정했습니다.
4. **생존·볼 수량 — 완료**: 기존 소모 공식의 배율을 1.25→1.75로 올려 직전 실행본보다 40% 빠르게 소모합니다. 이동/정지 차이와 프레임·정지·백그라운드 보호는 유지했습니다. 음식·물통·수원·나무 재생 규칙은 그대로입니다. 이미 가진 아이템은 줄이지 않습니다.
