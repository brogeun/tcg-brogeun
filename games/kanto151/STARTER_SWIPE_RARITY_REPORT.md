# 스타터 확대·희귀 출현·스와이프 개선 — 2026-09-26

## 완료한 변경

1. **첫 파트너 선택 — 완료**: 네 마리를 동시에 멀리 보여주던 장면을 선택한 한 마리만 크게 보여주는 카메라로 바꿨습니다. 모델 크기와 화면 비율에 맞춰 거리를 조절합니다. 좌우 스와이프, 화살표, 이름 버튼, 키보드 방향키로 바꿀 수 있습니다. 선택 화면에서만 캠프 기능 표식을 숨겨 얼굴을 가리지 않게 했으며 게임에 들어오면 복원합니다. 모바일 화면 회전 때 캔버스 크기가 어긋나던 문제도 수정했습니다.
2. **네 종 희귀도 — 완료**: 이상해씨·파이리·꼬부기·피카츄가 기존 둥지에서 15초마다 확정 출현하던 것이 원인이었습니다. 이 네 종의 기존 서식지는 유지하고, 유효 탐색 1회당 출현 확률 20%, 성공/실패 모두 탐험 시간 180초 대기를 적용했습니다. 연속 네 번 실패했다면 다음 탐색은 확정입니다. 대기 시간과 실패 횟수는 저장·재접속·지역 이동·사망 복귀에 포함합니다. 최초 파트너 선택은 확정 그대로입니다. 기존 시간·날씨·수집 조건을 바꾸거나 보유 개체를 줄이지 않았습니다.
3. **모바일 스와이프 — 완료**: 왼쪽 빈 화면을 끌면 이동, 더 멀리 끌면 달리기, 오른쪽을 쓸면 시점을 돌립니다. 두 손가락을 각각 추적해 이동과 시점을 동시에 조작합니다. 손 떼기·터치 취소·화면 회전·창 비활성화·메뉴 열기 시 입력을 정리합니다. 공격·회피·상호작용은 명시적인 버튼으로 유지했고 단순 화면 터치가 공격으로 이어지지 않습니다. 왼쪽 이동 영역을 덮던 행동 버튼은 오른쪽으로 옮겼습니다. PC 마우스·키보드 조작도 유지합니다.

## 수치와 저장 안전성

- 네 희귀 서식지: 확률 `0.2`, 재탐색 `180`초, 연속 실패 보장 `5`회. `data/biomes.json`과 대응 획득 데이터에 명시했습니다.
- 대기는 실제 탐험 진행 시간 기준입니다. 메뉴·일시정지·접속 종료 중에는 줄지 않습니다.
- 새 저장 필드 `expedition.rareNests`는 네 서식지 키, 다음 탐색 시각, 실패 횟수만 보관합니다. 구 저장에 없으면 미탐색 상태입니다. 잘못된 값은 검증에서 거부합니다.
- 저장 실패 시 탐색 기회를 소비하지 않습니다. 모델 로딩 실패 시에도 복원하며, 연속 입력으로 중복 생성하지 않습니다. 탐색 중 저장대 기록 갱신을 막고, 다른 저장/지역으로 전환된 뒤 늦게 끝난 처리가 현재 기록을 덮지 못하게 했습니다.
- 기존 생존 소모 1.75배, 음식·물통·보급 및 볼 수량 규칙은 이번에 변경하지 않았습니다. 5개 지역·151종·이로치·개체 고유 ID·진화·보스·퍼즐은 유지합니다.
