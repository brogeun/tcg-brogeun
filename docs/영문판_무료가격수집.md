영문판 카드는 운영 사이트에 348세트 · 26,030장 반영했습니다.
가격은 현재 무료 공개 페이지를 브라우저에서 열어 저장하고, PC에서 일괄 대조하는 방식으로 수집할 수 있습니다. 유료 API와 OpenAI API를 호출하지 않습니다.

1. PriceCharting에서 원하는 세트 가격표를 엽니다. 예: https://www.pricecharting.com/console/pokemon-chaos-rising
2. 화면 아래 통화를 **USD**로 선택하고 가격표가 완전히 나올 때까지 기다립니다. 세트는 **Exclude Variants**를 권장합니다. 아래로 내려가며 필요한 카드가 모두 표시됐는지 확인합니다.
3. **Ctrl+S → 웹페이지, HTML만**으로 이 프로젝트의 **price-import** 폴더에 저장합니다. 여러 세트를 저장해도 됩니다.
4. **영문판_가격가져오기.cmd**를 두 번 클릭합니다.
5. 끝나면 Codex에게 **`.cache/english-prices/report.json 확인하고 반영해줘`**라고 요청하면 됩니다.

거래 내역도 가져오려면 카드 상세에서 **PSA 10 Sold Listings** 탭을 누르고 표가 나온 뒤 같은 폴더에 HTML로 저장합니다. 세트 가격표와 카드 상세 파일을 한 번에 처리할 수 있습니다. 예: https://www.pricecharting.com/game/pokemon-chaos-rising/mega-greninja-ex-116

현재 시세와 과거 거래는 다릅니다.

- 세트 표의 **PSA10 추정가**는 PriceCharting이 계산한 현재 참고가격입니다. 실제 판매가 한 건으로 표시하지 않습니다.
- 카드 상세의 공개 판매 표는 **일부 최근 기록**입니다. 메가 개굴닌자 #116은 확인 당시 30건이 표시됐습니다. 전체 기간/전체 시장 거래량이라고 표시하지 않습니다.
- 이름·카드 번호·세트·PSA10 표기·판매 날짜를 대조합니다. 후보품, 다른 언어/등급, 묶음, 불명확한 항목은 제외합니다.
- 카드 번호가 같아도 이름이 다르면 자동 연결하지 않습니다. 리뷰 보고서에 남깁니다. 일부 세트 명칭 차이도 리뷰가 필요할 수 있습니다.
- 가격이 비어 있으면 0원이 아니라 **가격 없음**입니다. 못 읽은 카드는 **미수집** 상태입니다.
- HTML은 저장 시각을 확인 시각으로 보관합니다. 같은 파일을 다시 가져와도 확인 날짜를 새 날짜로 바꾸지 않습니다. 최신 자료가 오래된 자료로 덮이지 않습니다.
- 기존 판매 기록은 출처 URL로 중복을 제거하며 누적합니다. 처음부터 전체 과거 거래가 복원되는 방식은 아닙니다.

일반 HTTP 자동 요청은 403 보안 차단이 발생했습니다. 보안 확인을 우회하거나 유료 API를 구독하지 않습니다. **이 CMD는 저장 파일을 처리하는 반자동 도구이며, 348세트를 매일 무인으로 갱신하는 프로그램은 아닙니다.** 브라우저 저장 단계가 필요합니다.
