# 원피스 메루카리 보조 자료 수집

기존 수동 URL 5개를 보존하고 공개 검색에 실제로 나타난 상품 ID와 원본 상품 페이지에서 관측한 표시가를 수집한다. 현재 검증 브랜치 추적 대상은 65개다. 검색은 회당 20개, 상품 페이지 갱신도 기존과 같은 회당 20개 한도를 유지한다. 확인하지 않은 이전 매물은 원래 관측 시각·가격을 보존한다.

HTML에 직접 링크가 없는 경우에도 공개 페이지에 포함된 실제 상품 ID를 읽는다. ID를 추측하거나 비공개 API를 호출하지 않는다. HTTP 401/403/429는 중단 사유로 기록한다. 검색에서 번호가 같다는 사실은 같은 판본의 증거로 취급하지 않는다.

P-071·P-094·P-095·P-109는 공식 원본과 실제 판매 사진을 직접 비교해 일본어 인쇄·그림·카드번호·프레임이 일치함을 확인했다. 근거는 mercari-promo-review.jpg 및 config/onepiece-mercari-artwork-reviews-20261101.json에 있다. 실제 컨디션과 현재 판매 상태, 실거래 체결가는 확인한 것으로 표시하지 않는다. 검증된 사진 연결도 메루카리 매물 표시가 참고 자료이며 평가액에 자동 산입하지 않는다.

원피스 상품 연결 복구와 가격 선택은 별도 변경에서 검증한다. 가격은 스니덩 우선이며, 유효한 스니덩 가격을 확인하지 못하는 상태와 명확한 매물 없음은 구분한다. 유유테이·메루카리 모두 원래 통화와 관측 시각을 보존하고 화면에서 공통 환율로 원화 환산한다.

검증: 새 회귀 테스트 4개, 기존 메루카리 수집 테스트 17개, 수집 워크플로 테스트 19개 및 실제 원본 페이지 수집·참조 데이터 의미 검증이 통과했다. 실제 출처 접근 실패를 숨기거나 오래된 관측값을 최신가로 바꾸지 않는다.
